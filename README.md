## Akten ergänzen

Neue Fälle stehen in `assets/data/akten.json` (`nr`, `substanz`, `pdf`, `preview`, `seiten`). Das PDF liegt unter `akten/Akte_Fall_<NN>_<Substanz>.pdf`. Die Vorschau, etwa 600 px breit, liegt unter `assets/img/akten/Akte_Fall_<NN>_<Substanz>.webp` und `.jpg`. `preview` ist der Pfad ohne Endung. Die höhere Nummer wird zuerst gezeigt.
